# Study Decision Lab

CCT360 Lab 4: Interactive Logic.

This webpage recommends a personalized study session using the user's task, energy, available time, and distraction level. Conditional statements create four possible outcomes: Recharge, Reset Sprint, Steady Progress, and Deep Focus.

The project also stores completed sessions with `localStorage`. Progress messages change as the user completes more sessions, demonstrating JavaScript state based on previous actions.

## Technical requirements demonstrated

- Variables and a JavaScript state object
- `if`, `else if`, and `else` conditional logic
- Four possible outcome states
- Functions that select and render results
- Form, input, click, and confirmation interactions
- DOM manipulation
- Previous-action state saved between page visits

## Run locally

Open `index.html` in a browser. No build process is required.
